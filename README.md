# Aseprite 1.3.18.6 (portable, self-built)

Windows x64. Clone, then double-click `aseprite.exe`. No installer, no extra DLLs.

- `aseprite.ini` (empty) keeps settings inside this folder (portable mode).
- Built from the official source (https://github.com/aseprite/aseprite) for personal use.
- The Aseprite EULA does not allow redistributing compiled builds: keep this repo **private**
  and use it only on your own machines.
